# Chris Pawelczyk Portfolio Site

## Vision
Modern enterprise portfolio showcasing systems modernization, infrastructure operations, and technical problem solving.

## Design Direction
- Dark modern aesthetic
- Subtle ambient lighting effects
- Minimal and professional
- Inspired by benscott.dev
- Smooth but restrained animations

## Core Sections
- Hero
- About
- Experience Timeline
- Case Studies
- Resume / Contact

## Case Studies
1. Enterprise VMS Modernization
2. GSOC Modernization
3. Analytics / Queue Monitoring Concept
4. DriftWarden (future)

## Technical Goals
- Build a responsive React frontend
- Use Tailwind for styling and layout
- Use Framer Motion for subtle animations and transitions
- Include a subtle interactive background / cursor lighting effect
- Host on Vercel or Azure Static Web Apps
- Use GitHub for version control
- Configure basic CI/CD so changes deploy automatically

## MVP Scope
Single-page responsive portfolio with polished UI and static content only.
No backend.
No authentication.
No database.
No blog.
