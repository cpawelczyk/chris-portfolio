# Portfolio Frontend

This directory contains the React frontend for the Chris Pawelczyk portfolio site.

## Technologies

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Install

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

## Lint

```bash
npm run lint
```

## Build

```bash
npm run build
```
